SONGLES WEBSITE - HOW TO PUT IT ON NETLIFY
1. Go to https://app.netlify.com/drop
2. Drag this whole folder (songles-site) onto the page. Done - you get a live link.

HOW TO EDIT
- Text: open index.html in Notepad / any text editor and change the words.
- Pictures: replace the files in the "images" folder, keeping the same names:
    hero.jpg (big home photo), logo.png, about-1.jpg, about-2.jpg, about-3.jpg
- Instagram video cards: change the href="..." links in the VIDEOS section.
- Colours / fonts: top of style.css.
After editing, drag the folder onto Netlify Drop again (or use "Deploys" > drag folder).
